# Taipei Weekend Guide

A four-page vanilla HTML/CSS/JavaScript website created for the Web Programming Midterm Project.

## Pages

- `index.html` - project introduction and starting points
- `destinations.html` - destination cards, 2x2 grid, and transport table
- `itinerary.html` - live itinerary builder
- `tips.html` - travel-style quiz

## Run locally

From this folder, start any static file server. For example:

```powershell
py -3 -m http.server 4173
```

Open `http://127.0.0.1:4173/index.html` in a browser.

## Project requirements covered

- Four interconnected HTML pages with shared navigation
- External CSS file with responsive layout, hover effects, focus states, and consistent visual design
- Local SVG images with descriptive `alt` text
- 2x2 CSS grid, lists, internal links, external links, and a meaningful transport table
- Two different JavaScript/DOM features: live itinerary builder and travel-style quiz
- Code Explanation Report PDF: `docs/Code-Explanation-Report.pdf`

## GitHub Pages

1. Push the repository to GitHub.
2. Open the repository's **Settings → Pages**.
3. Select **Deploy from a branch**, choose the default branch, and select `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.
5. Verify every page and interaction from the published URL.

## Submission file

The iStudy submission requires one `.txt` file containing the GitHub repository URL, the GitHub Pages URL, and the Google Drive URL for the report PDF. The Google Drive report must be shared as **Anyone with the link** before copying its URL.
