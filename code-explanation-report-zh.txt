二、專案簡介

本網站名稱為 Taipei Weekend Guide，是一個介紹台北週末行程的旅遊網站。
網站以台北老街、貓空山區、夜市美食、捷運交通和城市景點為主題，
讓使用者可以先瀏覽景點，再選擇喜歡的活動，最後得到適合自己的簡單行程。

本網站的主要使用者是第一次來台北的旅客、交換學生，以及想快速規劃週末行程的使用者。
網站內容使用簡短文字，讓使用者可以快速找到景點和互動功能。


三、網站頁面與檔案結構

1. index.html
   首頁，介紹 Taipei Weekend Guide 的主題，並連結到其他三個頁面。

2. destinations.html
   景點介紹頁，使用卡片顯示台北老街、貓空、夜市與城市景點，
   另外使用 table 元素整理交通方式。

3. itinerary.html
   行程規劃頁，使用者可以勾選想去的活動，頁面會即時顯示活動數量、
   預估時間和已選擇的活動名稱。

4. tips.html
   旅遊風格測驗頁，使用者回答三個問題後，網站會給出旅遊風格建議。

5. css/style.css
   共用樣式檔案，負責網站的字型、顏色、間距、按鈕、卡片、表格與手機版排版。
   本次版本採用比較簡單的課堂作業風格，以白色背景、藍色主色和基本邊框為主。

6. js/script.js
   JavaScript 程式檔案，負責行程規劃器和旅遊風格測驗的互動功能。

7. assets/
   存放網站使用的 SVG 圖片，例如台北城市、捷運、夜市和貓空插圖。

8. tests/site.test.cjs
   Node.js 測試檔案，用來檢查頁面連結、HTML 元素、行程計算和測驗結果。


四、HTML 程式碼說明

1. 導覽列
   每個頁面都有相同的 nav 導覽列，讓使用者可以在四個頁面之間切換。
   導覽列使用 aria-label，幫助螢幕閱讀器理解這一區是主要導覽。

2. 語意化元素
   網站使用 header、main、section、article 和 footer 等語意化 HTML 元素。
   每個 destination card 使用 article，代表一個獨立的景點介紹內容。

3. 圖片
   所有主要圖片都使用 img 元素，並加入 alt 文字，讓圖片內容可以被理解。

4. 表格
   destinations.html 使用 table、caption、thead、tbody、th 和 td，
   整理捷運、步行與交通建議。caption 說明表格用途，th 表示欄位標題。

5. 表單
   itinerary.html 使用 checkbox 讓使用者選擇活動。
   tips.html 使用 radio button 讓使用者從每一題選擇一個答案。


五、CSS 程式碼說明

1. 共用變數
   :root 定義 --ink、--muted、--accent 和 --line 等顏色變數，
   讓四個頁面可以使用一致的顏色。

2. CSS Grid
   .destination-grid 使用 grid 排列景點卡片，在電腦版顯示兩欄，
   在手機版透過 media query 改成一欄。

3. Flexbox
   導覽列、按鈕列和頁尾連結使用 display: flex，方便排列內容並支援換行。

4. RWD 響應式設計
   CSS 使用 max-width: 820px 和 max-width: 560px 的 media query。
   當螢幕變窄時，首頁會從左右兩欄變成上下排列，
   卡片和表格也會調整寬度，方便手機使用。

5. 簡單視覺設計
   本版本刻意使用白色背景、藍色按鈕、灰色邊框和簡單卡片，
   移除過多陰影、動畫與裝飾，讓網站看起來像清楚易懂的課堂作業。


六、JavaScript 功能一：行程規劃器

itinerary.html 中的每一個活動都有 id、name 和 duration 資料。
使用者勾選或取消 checkbox 時，change 事件會重新計算目前的行程。

主要流程如下：

1. 讀取所有活動 checkbox。
2. 找出目前被勾選的活動。
3. 將活動 id 傳入 getPlannerSummary()。
4. 計算已選活動數量和總分鐘數。
5. 更新頁面上的 stops、minutes 和活動清單。

核心概念範例：

const summary = getPlannerSummary(selectedIds, activities);
count.textContent = summary.count;
duration.textContent = summary.duration;

getPlannerSummary() 是獨立的純函式，負責找出選取的活動、計算總時間，
並回傳 count、duration 和 items。把計算邏輯獨立出來後，較容易測試和維護。


七、JavaScript 功能二：旅遊風格測驗

tips.html 使用三組 radio button，分別詢問使用者喜歡的食物、旅行速度和活動時間。
表單送出時，JavaScript 使用 FormData 讀取答案。

如果使用者沒有完成所有題目，頁面會顯示提醒訊息；
如果三題都有回答，calculateQuizResult() 會根據答案計算推薦結果。

測驗結果可能包含以下類型：

1. Night-market explorer：適合喜歡夜市和美食的人。
2. Slow-street wanderer：適合喜歡慢慢散步和老街的人。
3. Mountain-air seeker：適合喜歡自然景色和山區的人。

結果會透過 DOM 更新到頁面，不需要重新整理瀏覽器。


八、測試結果

測試結果：

PASS the project has four connected HTML pages with shared navigation and CSS
PASS the website contains the required HTML teaching examples
PASS planner summary reports selected activity count, duration, and names
PASS quiz result gives a recommendation from the answer choices

測試確認以下內容：

1. 四個 HTML 頁面都有共用導覽列、CSS 和 JavaScript。
2. 網站包含圖片 alt、列表、表格、外部連結和 grid 等 HTML/CSS 範例。
3. 行程規劃器可以正確計算活動數量、總時間和活動名稱。
4. 旅遊風格測驗可以根據答案產生推薦結果。


九、製作心得與未來改進

這次製作讓我練習使用多個 HTML 頁面建立一個完整的小型網站，
也練習使用共用 CSS 保持頁面風格一致。

比較有挑戰的地方是讓互動功能和畫面內容互相配合，
例如勾選活動後，數字和清單必須立即同步更新。

如果未來繼續改進，可以加入更多台北景點、讓使用者拖曳調整行程順序，
或加入儲存行程功能。另外也可以加入更完整的無障礙測試和最新交通資訊。
